# 원불교 경기인천교구 교당 안내

경기인천교구 일반 교당 44개를 검색하고 주소·전화번호·블로그·지도 링크를 확인하는 정적 웹앱입니다.

## 구성

- 검색 화면
- 교당명과 주소만 표시하는 검색 결과
- 영상·블로그·주소·전화·지도 버튼을 조건부로 표시하는 교당 상세 화면

데이터는 `data/temples.json`에서만 읽습니다. 이 파일은 `경기인천교구_44개교당_통합운영표_v1.1.xlsx`의 공개 교당 44개 행에서 생성했습니다. 공식 공개 영상이 확인된 41개 교당은 상세 화면에 소개 영상을 표시하며, 영상이 확인되지 않은 교당은 해당 영역만 숨깁니다.

## 검증

Node.js 20 이상에서 다음 명령을 실행합니다.

```text
npm test
```

## 배포

백엔드와 환경 변수 없이 Vercel에서 정적 파일로 배포됩니다. 기존 Vercel 프로젝트가 GitHub `main` 브랜치와 연결되어 있으면 푸시 후 자동으로 새 배포가 생성됩니다.
